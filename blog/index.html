Loop Behind: Rethinking Where Extra Loops Pay Off in Looped Language Models

Extra loops pay off primarily by providing deeper Loop KV for later tokens rather than refining the current token

Looped language models improve performance by repeatedly applying shared layers, with gains commonly attributed to giving the current token extra computation. Disentangling per-token loop count from Loop KV depth on Dory-4B reveals that one loop reading loop-2 KV recovers 6.8 of 7.2 points, unlocking training-free parallel Loop-Behind Decoding.
